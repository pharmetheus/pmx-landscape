# Methods

## 1. Sources

Only these sources were used for the results:

1. **Frame.** FDA's "Novel Drug Approvals for [year]" pages, `https://www.fda.gov/drugs/novel-drug-approvals-fda/novel-drug-approvals-<year>`, for 2021 to 2025 (CDER novel approvals only; 238 drugs). The application number was taken from the label link on each row, otherwise from the Drugs@FDA link on the same row, and for four 2025 drugs (Lerochol, Nuzolvence, Exdensur, Nereus) from an openFDA generic-name lookup (`config/frame_overrides.json`).
2. **Document index.** openFDA drugsfda (`https://api.fda.gov/drug/drugsfda.json`): `submissions.application_docs` with type "Review" on original (ORIG) submissions, which point to the Drugs@FDA table-of-contents (TOC) page for the review package. The TOC page source gives the document base name and flags for which review documents exist.
3. **Documents.** PDFs from `https://www.accessdata.fda.gov/drugsatfda_docs/nda/<year>/`, of three types: Integrated Review (`IntegratedR`), Multi-Discipline Review (`MultidisciplineR`) and Clinical Pharmacology Review (`ClinPharmR`). Each was looked for in the approval-year folder, the following year's folder and the TOC's own folder. In total 241 documents for 238 drugs.
4. **Fallback only.** For Aduhelm, which has none of the three types, the Clinical (`MedR`), Other (`OtherR`) and Summary (`SumR`) reviews were searched. Clinical and Other reviews were also tested for about 30 drugs without a sponsor tool in 2022 and 2024; they added nothing, so they were not searched generally.

Not used: drug labels, Drug Trials Snapshots, clinicaltrials.gov, EMA documents, publications.

## 2. Text

Text was extracted page by page with `pdftotext`. Pages whose stripped text layer is shorter than 50 characters were treated as image-only and read with tesseract (150 dpi, grayscale, `--psm 3`); 6,026 pages across the five years. OCR text replaces the text layer for those pages. All search results refer to the PDF page index (1-based), not the printed page number.

## 3. Search

`config/patterns.json` holds the final patterns. They cover:

- **Estimation software:** NONMEM (including misprints such as "NONMEMS" and "NONMENE", lower case, and the expanded form "nonlinear mixed effects modeling 7.5.0" that some reviews print instead of the name), Monolix, Phoenix NLME, nlmixr/nlmixr2, Pumas, Stan/Torsten, saemix, FERX, S-ADAPT/ADAPT, Pmetrics, NLMIXED, WinBUGS/OpenBUGS/JAGS.
- **Auxiliary tools:** PsN (including "Perl-speaks-NONMEM"), Pirana, Xpose, mrgsolve, RxODE/rxode2, SimBiology/MATLAB, Berkeley Madonna.
- **PBPK:** Simcyp, GastroPlus, PK-Sim. **NCA:** Phoenix WinNonlin, PKanalix, other "Phoenix" mentions (excluding Phoenix, Arizona).
- **Markers:** SAS, R versions, and "population PK / popPK / PPK" (used to judge whether a popPK analysis is present).

## 4. Reading and attribution

Every software mention of an estimation or auxiliary tool was read in context. Review sections are labelled "Applicant's Position", "FDA's Assessment", "Reviewer's Independent Analysis" and similar, but these labels were used as hints only: appendices often reproduce Applicant text (for example the Applicant's model summary tables with an "FDA's comments" column) under FDA headings. Attribution rules:

- **Sponsor (Applicant):** the text describes the Applicant's analysis (Applicant report cited as source, Applicant model summary table, "the Applicant's popPK analysis was conducted using ...").
- **FDA reviewer:** the text describes the reviewer's own analysis ("Reviewer's Independent Analysis", "Source: Generated by an FDA reviewer", the reviewer's file listing on the FDA pharmacometrics server, "the review team performed simulations ...").
- **Not use:** reference-list citations, nonclinical (animal) models and OCR noise. An abbreviation-list entry alone counts only as indirect evidence.

## 5. Categories and evidence strength

Each drug gets one sponsor category:

| Category | Rule |
|---|---|
| Tool stated | The review states the sponsor software used for the popPK analysis |
| Tool stated (indirect) | The software is not stated as such, but the review shows it was used (see below) |
| popPK present, software not stated | A popPK analysis is described, but no software is named or implied |
| No popPK analysis in review | The searched reviews contain no popPK analysis (including cases where the review says the Applicant did not do one) |
| Review not posted | No review document found (0 drugs in 2021 to 2025) |

Evidence strength for tool families:

- **stated:** an explicit statement, e.g. "Software and Version: NONMEM 7.5.0" or "Population PK modeling was performed using Phoenix NLME Version 8.2".
- **indirect:** the software is implied by an Applicant artefact: a NONMEM control stream in the submitted file list, a column header "NONMEM Parameter" in an Applicant table, an Applicant table note about the NONMEM covariance step, reviewer figures built from "NONMEM outputs of the Applicant's model", a dataset file name, or an abbreviation list entry.
- **indirect, template phrase only:** the only evidence is the FDA template sentence "The final NONMEM data file for analysis contained ...". This phrase is unreliable: in Dawnzera (2025) and Rhapsido (2025) it was left unchanged although the Applicant used Phoenix NLME and Monolix. Thirteen drugs rest on this phrase alone; they are flagged so they can be excluded. Excluding them changes the NONMEM share of drugs with an identifiable tool from 92% to 91%.

The unit is the drug. A drug counts once per tool family however many analyses mention it.

## 6. Borderline decisions

These are the judgments most likely to differ between readers. Each is visible in the results CSV.

- Ponvory (2021): Monolix attributed to the Applicant from context (analysis of 13 Applicant studies); no explicit heading.
- Grafapex (2025): NONMEM recorded as FDA reviewer software (the reviewer's pediatric simulation used the Applicant's model); the Applicant's own software is not stated.
- Aphexda (2023): indirect NONMEM from a figure axis label ("NONMEM ID") read by OCR.
- Lerochol (2025): indirect Monolix, from a reviewer-edited template sentence ("The Monolix data file ...").
- Mounjaro (2022): NONMEM stated through "the L2 data item in NONMEM" in the Applicant's PK/PD model description.
- Tzield (2022): indirect NONMEM from a dataset name cited by the FDA reviewer.
- Leqvio, Pepaxto, Livmarli (2021) and Anktiva (2024): classed as "No popPK analysis in review" (the review says no model could be developed, or that the Applicant did not provide one, or shows only a table-of-contents heading).

## 7. How the search evolved, and the final check

The original work ran year by year (2024 first, then 2023, 2022, 2021, 2025) and the patterns were extended along the way: the expanded NONMEM name (during 2024), the capitalised "Perl Speaks NONMEM" for PsN (after 2022), case-insensitive NONMEM and Monolix and the misprints "NONMEMS"/"NONMENE" (during 2025), and exclusion of "Phoenix, AZ". The template-phrase problem was found in 2025 and applied to all years afterwards. A case-insensitive check of all "not stated" drugs added four corrections (Elahere, Tzield, Veozah, and the FDA reviewer's Monolix analysis for Ryzneuta).

Finally, the final patterns were run over all five years and compared with the recorded results (`07_verify.py`). This found two unrecorded auxiliary tools, RxODE for Hyrnuo and PsN for Wayrilz, which were added. All remaining matches are either recorded or listed in `config/known_exceptions.json`. No sponsor tool classification changed.

## 8. Limitations

- "Software not stated" (63 drugs, 26%) is not the same as "not NONMEM". It was 50% in 2021, when reviews used an older template without a "Software and Version" row, and 16 to 24% afterwards.
- OCR errors could still hide a software name on an image-only page, although the misprint patterns and the case-insensitive rerun reduce this.
- Only three review types were searched (plus the Aduhelm fallback). Software named only in other review documents or in the submission itself is not captured.
- A mention shows that the software was used for some popPK or related analysis; it does not show which tool produced the final model when several are named.
- FDA re-posts and re-redacts documents over time, and "(b) (4)" redactions occasionally sit next to software lists.
