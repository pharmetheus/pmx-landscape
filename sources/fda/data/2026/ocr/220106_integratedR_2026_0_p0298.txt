Final Model

Summary

Software and Version

Population PK modeling employed nonlinear mixed effects
modeling using the computer program NONMEM version 7.5.1
or higher. Post-processing of NONMEM analysis results was
carried out in R version 4.3.3. Model development was carried
out using first order conditional estimation with interaction
(FOCE-l) as estimation method. NONMEM model execution,
including visual predictive checks (VPCs) and stepwise
covariate modeling (SCM), were carried out using Perlspeaks-
Nonmem (PsN), version 5.3.1

Model Structure

PK of brepocitinib was described with oral input with a lag-
time for tablets into a dosing depot, followed by first-order
absorption into a two-compartment disposition model with
linear elimination from the central compartment.
