19.5.6.3. Methods

All simulations were performed using the PK/PD Profiles mode in the Simcyp® Simulator
(Version 22, Certara, Sheffield, UK) unless otherwise noted. Simulations were performed using
the default healthy subject or cancer population model. Age, sex, number of subjects, and dosing
regimens were consistent with the actual trial design. Ten trials were simulated for each scenario.
A schematic diagram of the PBPK modeling and simulation strategy is shown in Figure 44,
which summarizes the studies used for iberdomide model development and verification and
model applications in predicting the DDI potential of iberdomide as an object of weak and
moderate CYP3A4 induction or inhibition. The final model input parameters are summarized in
Table 101. The iberdomide PBPK model consists of an Advanced Dissolution, Absorption and
Metabolism (ADAM) model for describing drug absorption in each gut segment, a full PBPK
model for drug distribution, and an enzyme kinetics model for elimination. The Simcyp library
files for itraconazole, fluconazole, cimetidine, efavirenz, modafinil were used without
modification unless otherwise noted.
