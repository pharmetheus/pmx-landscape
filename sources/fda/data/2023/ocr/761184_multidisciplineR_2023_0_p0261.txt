14.3.3.2.3. Model Development
The following steps were followed in developing an alternative PKPD model:

e The structural model given in equation (2.1) was used as the base model. However, in
contrast to the Applicant’s base model, baseline IGF-1 was not estimated, instead for
everyone, baseline IGF-1 was the mean of observed IGF-1 values before starting somatrogon
treatment. PK fixed effects parameter estimates were fixed to estimated typical values from
the PopPK model and the individual PK parameters were derived using the typical values,
the time varying covariates and the empirical-bayes estimates for ETA derived from the
PopPK model.

e From the base model, the plot of CWRES versus TIME showed increasing trend for CWRES
overtime. This indicated that individual predictions (IPRED) plateaued while DV continued
to increase overtime. The base model had to be modified for IPRED to continue to increase
as DV. In the Applicant’s model, baseline IGF-1 increased with age, this is supported by
literature. Figure 49 shows that indeed, baseline IGF-1 increased with age in the present
cohort.
