Premature Discontinuations and Missing Data

The primary multiple imputation analysis relied on the missing at random assumption,
suggesting that all observed response trajectories can be used to impute the unobserved
outcomes. Specifically, the missing data were imputed sequentially by each visit using a
regression method. The imputation regression model included treatment group, race, and

baseline age as factors, and body weight at all previous visits (including baseline weight) as
covariates.
