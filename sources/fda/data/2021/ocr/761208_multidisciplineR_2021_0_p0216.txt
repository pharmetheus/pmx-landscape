Exposure Response Analyses:

Exposure Metrics: The population PK analysis showed that there was no appreciable accumulation of
ADC and MMAE with repeated dosing. Therefore, Cycle 1 exposure measures were used for all
exposure-response analyses. Cycle 1 was defined as the interval between the first and the second doses.
Moreover, trough concentrations of ADC were either below quantification limit (BQL) or close to it.
Therefore, ADC trough (minimum) concentration was not a useful measure of exposure. Thus, the
individual estimates of the following exposure measures in Cycle 1 were used for the exposure-response
analyses in addition to average ADC concentration from time zero to the end of the cycle in which event
occurred (CavgLast):

Data: The database for the exposure-safety analysis included the data from 272 subjects administered

GCT1015-04 (cutoff date February 6, 2020). The database for the exposure-efficacy analysis included the

Exposure Safety Analyses: Treatment-emergent adverse events (AEs) investigated include treatment
related AEs, All SAEs, treatment-related Grade 3+ TEAEs, treatment-related TEAEs leading to dose
interruption, treatment-related TEAEs leading to dose reduction, treatment-related TEAEs leading to
dose discontinuation, Grade 2+ bleeding TEAEs, Grade 2+ ocular TEAEs, and Grade 2+ peripheral
neuropathy. For each TEAE type, linear logistic regression base models were implemented to assess the
relationship between the probability of TEAE occurrence and exposure. To define the confidence
interval for the logistic regression function, 1000 bootstrap samples were drawn with replacement from
the analysis population, and the logistic regression base model was fitted to each of these samples. For
each exposure value, 95% confidence interval of the logistic regression curve was defined as the 5th and
95" percentiles of the model predictions among 1000 bootstrap data sets. A significance level of a =
0.05 was used for evaluation of the exposure coefficient of the base model (slope parameter). For each
TEAE type, a covariate analysis was conducted using the full model approach. The full model had the
following structure: logit(EVENT) ~ Intercept + Exposure + AGE + WT + SUMDIAM + ALB + LDH +TFE +
factor(SEXF) + factor(USA) + factor(CERVICAL) + factor(RENAL2) + factor(RENAL3) + factor(HEP) +
