Results

PK/PD Target Attainment Analyses for Efficacy

An information request was sent on September 15, 2023, for additional PTA analyses to support
the dosing regimen in subjects with renal impairment based on renal function as determined by
de-indexed eGFR (expressed in units of mL/min). Specifically, we request the Applicant to
update the simulation of cefepime and enmetazobactam at the proposed dosing regimen using the
de-indexed eGFR in various renal impairment groups with appropriate categories (e.g., (0, 10],
(10, 20], (20, 30], (30, 45], (45, 60], (60, 90], (90, 120], (120, 130], (130, 150], (150, inf}).

Based on the response to information request received on September 29, 2023, the PTA analyses
across different renal function categories were recalculated using de-indexed eGFR, supporting
the final proposed dosing regimen for subjects with renal impairment using de-indexed eGFR.

regimens shown in Table 103 with the joint cefepime-enmetazobactam target are shown in
