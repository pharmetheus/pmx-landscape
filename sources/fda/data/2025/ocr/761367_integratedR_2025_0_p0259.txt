BLA 761367
Andembry / garadacimab

Screened Analysis Set: All subjects who provided written informed consent.

All Treated Subjects Analysis Set: All subjects in the Screened Analysis Set who were assigned
to treatment. The All-Treated Subjects (ATS) Analysis Set was analyzed using the treatment to
which the subject was assigned, regardless of the treatment actually received. This was the main
set used for efficacy analyses.

Safety Analysis Set: All subjects in the ATS Analysis Set who received at least 1 dose of
investigational product. The Safety Analysis Set was analyzed using the actual treatment
received (the actual treatment was planned to be garadacimab for all subjects, but the dose level
could have been incremented from the initially planned 200 mg). This was the main set used for
safety analyses.

Per Protocol Analysis Set: All subjects in the ATS Analysis Set who received at least one dose of
investigational product and who complied with the protocol. Decisions regarding exclusion from
the Per Protocol Analysis Set were planned to be made and documented before database lock.
